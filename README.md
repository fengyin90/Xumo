# 续墨 · XUMO

一部给长篇小说用的续写工作台。核心不是聊天，是**上下文管理**：
写完十万字之后，模型仍然记得人物是谁、伏笔埋在哪里、笔法什么样。

## 这是什么

写长篇最麻烦的不是"写不出来"，是**写了二十万字以后，模型忘了前面发生过什么**。
续墨把"让模型始终记得"这件事做成了核心：把设定、记忆、语料、上文窗口
拼成一份上下文，每次续写都完整注入，故事不会断线。

## 运行

需要 Python 3.10+ 和 PyQt6：

    pip install PyQt6
    python main.py

首次启动点右下角「引擎设置」，填入 API Key。
默认走 DeepSeek，任何 **OpenAI 兼容接口**（base_url 以 /v1 结尾）都可用。

## 打包成 exe（Windows）

已备好脚本，先装 PyInstaller：

    pip install pyinstaller
    build.bat

产物在 dist/Xumo.exe，单文件、免安装。
**exe 是便携的**：作品数据存在 exe 同级的 projects 文件夹里，exe 挪到哪，作品跟到哪。

## 怎么用

### 1. 写设定

右栏「设定」写个大概，哪怕只有一句「都市修仙，主角是外卖员」。

- 点「**补全设定**」：AI 按你的方向，把人物、境界、势力、地名补全成完整设定
- 点「**取书名**」：AI 拟几个候选书名，点选即改作品名

### 2. 写正文

底部点「**续 写**」（Ctrl+Enter），或「**一键生成**」连写到你设定的字数。

空稿会自动走**开篇模式**：第一句就落到具体场景，主角迅速出场，带钩子。

### 3. 设定自动跟上

「一键生成」写完后，程序**自动通读全文**，把新出现的人物、事件、伏笔
并进设定。写了几十万字也不用担心设定过期。

## 上下文怎么工作

一次请求由几层拼成，顺序即优先级：

| 层 | 来源 | 作用 |
|---|---|---|
| 作品设定 | 你写的 + AI 补全的 + 自动分析 | 人物、世界、境界、势力、笔法，最高优先级 |
| 前情记忆 | 旧正文自动压缩而成 | 装下超出窗口的漫长前文 |
| 参考语料 | 你上传的设定 / 大纲 / 前作 | 硬性设定，不得违背 |
| 上文窗口 | 当前章末尾若干字 | 保证句子接得上 |

正文超过「上下文预算」后，超出部分会**自动**交给模型压缩成前情提要，
追加进记忆 —— 窗口永远装得下，故事不会断线。中栏底部显示预算占用。

## 自动接续

单次回复受 max_tokens 限制，会在句子中间硬切。检测到截断后，
程序自动再请求一轮，把已写内容回填、要求「继续往下写，不要重复」，
直到模型自己收尾。所以不会出现「写着写着停在半句」。

## 阅读模式

标题栏点「阅读」→ 独立窗口通读全书。左栏目录、右栏正文，可调字号，
顶栏与目录鼠标靠近才滑出。关掉再开，回到上次读到的位置。

## 操作

| 动作 | 方式 |
|---|---|
| 续写 | 底部「续 写」/ Ctrl+Enter |
| 接龙续写 | 「更多」菜单 / Ctrl+Shift+Enter —— 以光标为起点重写其后内容 |
| 开篇生成 | 「更多」菜单 —— 为空白新作品写开头 |
| 重排段落 | 「更多」菜单 —— 让 AI 重新安排换行，不改一个字 |
| 中止 | Esc 或再点一次按钮 |
| 新建章节 | Ctrl+N |
| 保存 | Ctrl+S（另有 8 秒自动保存） |
| 添加语料 | 右栏「添加文件」，或直接把文件拖进窗口 |
| 章节管理 | 左栏右键：重命名 / 删除 |
| 阅读 | 标题栏「阅读」 |
| 作品管理 | 标题栏「作品」：新建 / 打开 / 删除 / 导入备份 |
| 导出 | 标题栏「导出」：全部章节 / 当前章节 / 设定资料 / 项目备份 |
| 配色 | 标题栏「简约蓝 / 温馨粉」一点即换 |

## 文件

    theme.py      设计令牌与样式表（两套配色）
    store.py      项目数据模型，单文件 JSON，存于 projects
    ai.py         流式续写、上下文装配、记忆压缩、设定分析
    ui.py         界面
    main.py       入口
    build.bat     Windows 打包脚本

## 数据位置

作品存于程序目录下的 projects 文件夹，每部一个 JSON 文件。
每次保存前自动留一份历史版本在 projects/backup，保留最近 40 份。

**换机器**：用「导出 → 项目备份」拷 json，在另一台机器「作品 → 导入备份」。

## 注意

- 本项目只负责界面与上下文管理，**不提供模型**，需自备 OpenAI 兼容接口的 API Key
- projects 文件夹内含 API Key 与作品正文，请勿提交到公开仓库（已在 .gitignore 中排除）
